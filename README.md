# Digital Signal and Image Processing

Welcome to the **Digital Signal and Image Processing** repository! This project contains Python scripts and Jupyter Notebooks focusing on core concepts, algorithms, and practical implementations of signal processing and digital image transformations.

---

## 🛠️ Tech Stack & Dependencies

* **Language:** Python 3.x
* **Environment:** Jupyter Notebook / Google Colab
* **Libraries:** `numpy`, `matplotlib`, `scipy`, `opencv-python`, `pillow`

---

## 📁 Repository Structure & Topics

### 1. Digital Signal Processing (DSP)
* **Discrete-Time Sequences:** Simulation and visual analysis of fundamental discrete signals (`Simulate Discrete time Sequences .ipynb`).
* **Convolution Techniques:** Implementations of linear convolution and circular convolution on discrete signals (`linear convolution and circular convolution on discrete time signals.py`).
* **Correlation Analysis:** Cross-correlation and auto-correlation algorithms for measuring signal similarity and time shifts (`Cross-correlation and Auto-correlation.py`).

### 2. Digital Image Processing (DIP)
* **Image Transformations:** Implementation of non-linear spatial transformations, power-law (gamma) intensity corrections, and visual enhancement techniques (`Original_image_to_gamma_image.ipynb`).
